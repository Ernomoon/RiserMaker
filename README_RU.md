# Riser Maker — плагин-разгон для FL Studio (VST3, Windows)

Что делает: ты пускаешь вокал (или бит / драмку / мелодию) через плагин, он **сам записывает** фразу
и делает из неё **обратный реверб-разгон** нужной длины (1/4 … 8 тактов, под темп проекта).
Готовый разгон слушаешь кнопкой LISTEN и **перетаскиваешь мышью в плейлист** (или EXPORT WAV).
Длина файла = ровно N тактов, а конец разгона = начало вокала. Положил файл за N тактов до фразы — всё совпало.

## Как пользоваться
1. Вставь плагин в слот эффекта на дорожке с вокалом.
2. Нажми Play в FL Studio и дай прозвучать началу фразы (хватает 1–3 секунды). Плагин пишет сам.
   Когда остановишь воспроизведение (или будет пауза ~0.6 с) — разгон появится в окне.
   Можно и просто перетащить аудиофайл в окно плагина.
3. Ручка REVERSE — длина разгона (1/4, 1/2, 1, 2, 4, 8 тактов).
4. VOX — убирает «ссс» (красные метки в режиме RAW), INST — для бита/мелодии.
5. Мини-эквалайзер: тяни левый кружок — срез низов (LOW CUT), правый — срез верхов (HIGH CUT). Двойной клик — сброс.
6. PHONE / CHORUS / DRIVE / TREMOLO: значок питания — вкл/выкл, клик по названию — открывает ползунки.
7. LISTEN / LOOP — прослушка. Тащи волну в плейлист (или EXPORT WAV). RESET — очистить записанное.

## КАК ПОЛУЧИТЬ ГОТОВЫЙ УСТАНОВЩИК (без программирования, бесплатно)
Собирать нужно на Windows-компьютере с Visual Studio, но у GitHub есть бесплатный облачный сборщик — он всё сделает за тебя.

1. Зарегистрируйся на https://github.com (бесплатно).
2. Нажми «+» → **New repository**, назови `RiserMaker`, поставь **Public**, создай.
3. Нажми **uploading an existing file** и перетащи туда ВСЁ содержимое распакованной папки
   (папки `Source`, `installer`, файлы `CMakeLists.txt` и остальные). Нажми **Commit changes**.
4. Папка `.github` может не загрузиться (она «скрытая»). Проверь: если в репозитории нет `.github/workflows/build.yml`:
   нажми **Add file → Create new file**, в имени напиши `.github/workflows/build.yml`,
   вставь туда содержимое файла `GITHUB_WORKFLOW_build.yml.txt` и сохрани (Commit).
5. Открой вкладку **Actions**. Сборка запустится сама (если нет — «Build Windows plugin + installer» → **Run workflow**).
   Подожди 10–15 минут, пока появится зелёная галочка.
6. Открой завершённый запуск, внизу в разделе **Artifacts** скачай **RiserMaker-Windows**.
   Внутри: `RiserMaker-Setup.exe` (установщик) и `RiserMaker-VST3-manual.zip` (запасной вариант).
7. Запусти `RiserMaker-Setup.exe`, затем в FL Studio: **Options → Manage plugins → Find plugins** (или Find installed plugins).
   Плагин появится в списке (Fx). 

Если сборка упала красным крестиком — открой запуск, скопируй текст ошибки и пришли мне, я исправлю.

## Ручная сборка установщика (если уже есть собранный Riser Maker.vst3)
Установи Inno Setup (https://jrsoftware.org/isdl.php), открой `installer/RiserMaker.iss`, нажми Compile (F9).
Путь к `.vst3` в блоке [Files] при необходимости поправь.

## Ограничения этой версии
- Только Windows VST3 (FL Studio 20.8+/21+/2024).
- Реверб — встроенный (Freeverb-класс); качество можно улучшить на этапе доводки.
- Дизайн — рабочий, финальную полировку сделаем следующим шагом.
